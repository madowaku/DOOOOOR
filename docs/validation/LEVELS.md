# 全8問の検証レポート

npm run validate で再生成。U=上、R=右、D=下、L=左。手数は移動と開扉を兼ねる1歩で数え、壁への入力は数えない。最小開扉数は最短手数とは別に全到達状態から求める。

| 面 | 名前 | 最短手数 | 最小開扉数 | 標準解 | 到達状態 |
|---|---|---:|---:|---|---:|
| 001 | OPEN | 1 | 1 | R | 2 |
| 003 | SWING | 4 | 1 | DDLU | 6 |
| 005 | NOT YET | 25 | 4 | URDDLLLURDRRUULDLRRUULDLU | 87 |
| 009 | COME BACK | 11 | 1 | DDDRRRUUULL | 18 |
| 011 | TWO WAYS | 4 | 2 | RRDL | 9 |
| 012 | CHOOSE | 12 | 3 | LDRURDDRULUR | 64 |
| 018 | HINGE KNOT | 15 | 4 | DRUULRRULDLUUUL | 70 |
| 020 | DOOOOOR | 18 | 4 | DDRRUUULDLRRUULDLU | 177 |

## 001 OPEN

下への通路は壁。Aを右に押す1手が唯一の最短解。開いた葉は右下との境界に残る。

- 標準解の開扉順: A:R
- 全クリア状態で必ず開く: A
- 全クリア状態で必ず閉じる: なし
- 開扉制限: A=R
- 意図的な失敗例: なし（導入面）
- 近道監査: 開扉なしでは到達不可。全状態の最短路を採用し、標準解より短い解は存在しない。

## 003 SWING

Aを下へ押すと左への辺が閉じる。そのまま左には行けず、下段を回って出口へ。

- 標準解の開扉順: A:D
- 全クリア状態で必ず開く: A
- 全クリア状態で必ず閉じる: なし
- 開扉制限: A=D
- 意図的な失敗例: なし（導入面）
- 近道監査: 開扉なしでは到達不可。全状態の最短路を採用し、標準解より短い解は存在しない。

## 005 NOT YET

正面Aの右押しは今は罠だが、全解で後から同じA:Rが必須。Bを下へ開け、長いCを左へ動かして戻り、Aを右へ。最後に長いDを下へ開く。

- 標準解の開扉順: B:D → C:L → A:R → D:D
- 全クリア状態で必ず開く: A, B, C, D
- 全クリア状態で必ず閉じる: なし
- 開扉制限: A=R, B=D, C=L, D=D
- 意図的な失敗例: R。最後の1手の前はクリア可能、直後は不可能。UNDOで復帰できる。
- 近道監査: 開扉なしでは到達不可。全状態の最短路を採用し、標準解より短い解は存在しない。

## 009 COME BACK

出口は右隣だがAは禁止側。左辺を3歩下り、下辺のBを右に開き、右辺を上って上辺から戻る11手の大回り。Bの葉は中央の抜け道を塞ぎ、対角の角まで歩く必要がある。

- 標準解の開扉順: B:R
- 全クリア状態で必ず開く: B
- 全クリア状態で必ず閉じる: A
- 開扉制限: A=L, B=R
- 意図的な失敗例: なし（導入面）
- 近道監査: 開扉なしでは到達不可。全状態の最短路を採用し、標準解より短い解は存在しない。

## 011 TWO WAYS

Aを右に押すと真下の出口への辺を塞ぐ。右から回り、Bを左へ押して出口へ。全クリア状態でA:RとB:Lが必須。2枚とも両方向に物理的な回転余地があり、右押しと左押しを実際に体験する。開扉0の迂回解はない。

- 標準解の開扉順: A:R → B:L
- 全クリア状態で必ず開く: A, B
- 全クリア状態で必ず閉じる: なし
- 開扉制限: A=R/L, B=R/L
- 意図的な失敗例: なし（導入面）
- 近道監査: 開扉なしでは到達不可。全状態の最短路を採用し、標準解より短い解は存在しない。

## 012 CHOOSE

両方向のBは左右とも実際に押せる。右へ押すと長いAの回転を妨げて詰み、左へ押すことが全解で必須。B→A→Cの順に三枚を動かす。

- 標準解の開扉順: B:L → A:U → C:L
- 全クリア状態で必ず開く: A, B, C
- 全クリア状態で必ず閉じる: なし
- 開扉制限: A=U, B=R/L, C=L
- 意図的な失敗例: ULDR。最後の1手の前はクリア可能、直後は不可能。UNDOで復帰できる。
- 近道監査: 開扉なしでは到達不可。全状態の最短路を採用し、標準解より短い解は存在しない。

## 018 HINGE KNOT

Aを動かすと長いBの掃引領域が空き、Bを動かすと長いCを開けられる。A→B→C→Eの四段階が全解で必須。最後の共有蝶番ではDを閉じて残す。

- 標準解の開扉順: A:D → B:L → C:D → E:L
- 全クリア状態で必ず開く: A, B, C, E
- 全クリア状態で必ず閉じる: D
- 開扉制限: A=D, B=L, C=D, D=L, E=L
- 意図的な失敗例: DRUULRRULDLUUL。最後の1手の前はクリア可能、直後は不可能。UNDOで復帰できる。
- 近道監査: 開扉なしでは到達不可。全状態の最短路を採用し、標準解より短い解は存在しない。

## 020 DOOOOOR

Aは下へ押すことが必須で、上へ押すと詰む。Cは早く右へ開くと詰むが、Aを先に動かしてから同じ右押しを必ず使う。Eを開くと長いBと干渉するため、全解で閉じて残す。長いBとCを動かした後に、最後の長いDへ。

- 標準解の開扉順: A:D → B:L → C:R → D:D
- 全クリア状態で必ず開く: A, B, C, D
- 全クリア状態で必ず閉じる: E
- 開扉制限: A=U/D, B=L, C=R, D=D, E=L
- 意図的な失敗例: LDRU。最後の1手の前はクリア可能、直後は不可能。UNDOで復帰できる。
- 近道監査: 開扉なしでは到達不可。全状態の最短路を採用し、標準解より短い解は存在しない。

## スコープ

優先8問のみ収録。002 / 004 / 006–008 / 010 / 013–017 / 019は未収録。005は正面Aを後から同じ右方向に押すことが必須。012はBの左右の選択が必須。018は四枚の順序、020は後回し・方向・閉じる判断を統合。人間による難易度・楽しさの評価は自動検証とは別。

## 全クリア状態に対する強い条件

| 面 | 最小両方向開扉数 | 全解で要求する操作 | 全解で要求する順序 |
|---|---:|---|---|
| 001 | 0 | 指定なし | 指定なし |
| 003 | 0 | 指定なし | 指定なし |
| 005 | 0 | A:R, B:D, C:L, D:D | A → D, B → A, B → C, B → D, C → D |
| 009 | 0 | B:R | 指定なし |
| 011 | 2 | A:R, B:L | A → B |
| 012 | 1 | A:U, B:L, C:L | A → C, B → A, B → C |
| 018 | 0 | A:D, B:L, C:D, E:L | A → B, A → C, A → E, B → C, B → E, C → E |
| 020 | 1 | A:D, B:L, C:R, D:D | A → B, A → C, A → D, B → D, C → D |

「標準解が使う」と「全ての解で必要」は区別する。012/020は両方向ドアを使わない解を禁止し、逆側から合法に押すと詰む実例も検証。詳しくは ../LEVEL_DEPTH_REVIEW.md。

## 後回し・方向・閉じる選択の証拠

### 005

同じ方向を後回し: A:R。早い失敗例 R、全解で後にこの操作が必須。

### 012

必須の方向: B:L。逆向きの合法な失敗例 ULDR。

### 018

全解で閉じる: D。実際に押せる失敗例 DRUULRRULDLUUL。

### 020

同じ方向を後回し: C:R。早い失敗例 LDRDRRUUULDR、全解で後にこの操作が必須。

必須の方向: A:D。逆向きの合法な失敗例 LDRU。

全解で閉じる: E。実際に押せる失敗例 DDRRUUULDDL。
